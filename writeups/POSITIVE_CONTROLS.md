# Observation supervision and the terminal format

WebWorld-8B explicitly predicts the next state given actions and history in web environments. On the fixed SWE transcripts its recalibrated content score corresponds to 1.26× the instruct starting size. Its primary plain sandbox binding difference from 8B instruct is −0.1 percentage points. This cross-domain control leaves open what a matched Qwen3 checkpoint trained directly on shell responses would achieve. [WebWorld](https://huggingface.co/Qwen/WebWorld-8B) · [SWE results](../swe/results/size_equiv/size_equiv_swe.md)

Other proposed controls fall outside the matched panel. SWE-World’s transition models predict stdout, stderr and exit status conditioned on a SWE-specific prompt and use a Qwen2.5 lineage. Meta’s CWM uses another tokenizer and a Python execution format. Qwen-AgentWorld covers terminal and SWE state transitions, but uses a Qwen3.5 mixture-of-experts base and a different tokenizer. Comparing such systems would require choices about reasoning prefixes and rendering as well as an appropriate new size ladder. [SWE-World](https://huggingface.co/RUC-AIBOX/SWE-World-SWT-32B-wo-cot) · [CWM](https://huggingface.co/facebook/cwm) · [Qwen-AgentWorld](https://huggingface.co/Qwen/Qwen-AgentWorld-35B-A3B)

Nemotron-Terminal’s training data use Terminus-2 conventions, including agent-generated command structures and terminal response wrappers. Its training traces can include thinking blocks. This close alignment offers a format-specific explanation for its improved command imitation in AgenticPPL. The publication does not establish the observation loss mask or the exact base versus instruct start. Timing limits direct overlap with the later released trajectories, while overlap in underlying tasks remains unresolved. TMax uses a persistent-shell harness, and CodeScout uses the OpenHands shell scaffold. CodeScout reports masking environment responses.
