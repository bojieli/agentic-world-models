# Size-equivalent multipliers (counterfactual sandbox benchmark)

Data: `items.jsonl.gz` v2, primary pool = S2+S3+S2h+S3h (3600 pairs), plain rendering, mask nocopy, T = 1.
Primary metric: binding accuracy y = mean over pairs of 1[I > 0] (0.5 on ties).
Params: x = log2(non-embedding params) from `swe/configs/params.json`.
CIs: one joint env-cluster bootstrap with 2000 draws that resamples every model, the deltas and the ladder together.

**(a) Size multiplier vs the model's own start (PRIMARY: inverse interpolation on the ladder).**
Ladder: Qwen3 instruct 0.6/4/8/14/32B for instruct starts, points (x_k, y_k). Per draw, y is made monotone in x by
a running max (isotonic), then x* = piecewise-linear inverse of that curve at the post-trained model's y_m
(`np.interp(y_m, y_iso, x)`), log2 n = x* - x_start, n = 2^(log2 n). If y_m lies outside [y_min, y_max] of the
curve, log2 n is censored to the ladder range [x_min - x_start, x_max - x_start] and marked `>` or `<`.
Upper censor: +2.17 for an 8B start (32B/8B non-embedding), +1.24 for a 14B start, 0 for a 32B start (a 32B
model can only be bounded, never given n > 1).
**Sensitivity: global OLS.** y = a + b*x fitted over the same ladder; log2 n = (y_m - y_start) / b, same censoring.

**(b) Second reference: the same-size base model.** Delta = y_m - y(Qwen3-<size>-Base), paired, with CI; verdict
"above base" / "below base" if the CI excludes 0, else "n.s.". No n against base: the base ladder is flat above
4B (steps 4->8B and 8->14B n.s.). There is no Qwen3-32B-Base, so 32B models have no (b).
Klear-Reasoner-8B-SFT starts from Qwen3-8B-Base: its own-start row is a delta vs base only (no n); an extra row
("vs instruct") gives delta and n against the instruct Qwen3-8B for comparability.
